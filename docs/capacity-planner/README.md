# Capacity Planner build pack

`build-pack.html` is the approved-for-review plan for adding a capacity planner (Delivery mode) to the SDR OS app.
Open it in a browser. It covers findings, objectives, personas, business and functional requirements, the
capacity engine rules, screens, board specifications, workflows, automations, technical design, seeding,
sprint plan, the sequential build prompts (section 22), tests, RAID and traceability.

Status: v1.8 (26 Oct 2026), client edition. Adds named delivery teams (Delivery Teams board, My team view, lent and borrowed hours). Overnight build plan; admin checklist in admin-setup.html.
Start the build with prompt P-01 in section 22, after sign-off.
